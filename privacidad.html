Política de privacidad

Última actualización: septiembre de 2026

En esta política se explica cómo se trata la información personal cuando visitas este sitio web o contactas con Asier Mariné a través de sus canales de comunicación.

1. Responsable del tratamiento

El responsable del tratamiento de los datos personales recogidos a través de este sitio web es:

Nombre: [Nombre y apellidos]
Correo electrónico: tu@email.com
Sitio web: www.tudominio.com

Este sitio web tiene como finalidad principal presentar mi perfil profesional, proyectos y trabajos realizados, así como facilitar un medio de contacto para posibles oportunidades laborales y proyectos profesionales.

2. Datos que se recopilan

A través del formulario de contacto de este sitio web pueden recopilarse los datos que el usuario decida proporcionar, como:

  • Nombre.
  • Dirección de correo electrónico.
  • Contenido del mensaje.
  • Cualquier otra información que el usuario incluya voluntariamente en el mensaje.

No se solicitan datos personales que no sean necesarios para atender la solicitud de contacto.

3. Finalidad del tratamiento

Los datos proporcionados mediante el formulario se utilizan exclusivamente para:

  • Recibir y responder a solicitudes de contacto.
  • Atender consultas relacionadas con oportunidades laborales o proyectos profesionales.
  • Mantener una comunicación derivada de la solicitud realizada por el usuario.

Los datos no se utilizarán para enviar comunicaciones comerciales no solicitadas ni se incorporarán a listas de publicidad o newsletters sin una base jurídica adecuada.

4. Base jurídica

La base jurídica para el tratamiento de los datos será la atención de la solicitud de contacto realizada por el propio usuario y, cuando corresponda, la adopción de medidas precontractuales solicitadas por este.

Cuando el tratamiento requiera el consentimiento del usuario, este será solicitado de forma específica y diferenciada.

5. Destinatarios y proveedores de servicios

Para gestionar el formulario de contacto se utiliza Formspree, un servicio externo que permite recibir y gestionar los mensajes enviados desde el sitio web.

Los datos introducidos en el formulario son transmitidos a Formspree para poder procesar y entregar el mensaje al responsable del sitio web.

Formspree actúa como proveedor del servicio de gestión del formulario y puede tratar los datos de acuerdo con sus propias condiciones y políticas de privacidad. Cuando resulte aplicable, se adoptarán las garantías necesarias para las transferencias internacionales de datos.

Puedes consultar la información sobre privacidad y seguridad de Formspree en su documentación oficial.

Además, los datos pueden ser almacenados en el servicio de correo electrónico utilizado por el responsable para recibir y responder a los mensajes.

No se venden ni ceden los datos personales a terceros con fines comerciales.

6. Conservación de los datos

Los datos se conservarán únicamente durante el tiempo necesario para atender y gestionar la solicitud de contacto y, cuando exista una relación profesional derivada de dicha comunicación, durante el tiempo necesario para gestionar dicha relación y cumplir las obligaciones legales aplicables.

Los datos podrán permanecer temporalmente almacenados en los sistemas de los proveedores utilizados para gestionar el formulario y las comunicaciones electrónicas.

7. Derechos del usuario

El usuario puede solicitar el ejercicio de los siguientes derechos respecto de sus datos personales:

  • Acceso a sus datos personales.
  • Rectificación de datos inexactos.
  • Supresión de sus datos cuando proceda.
  • Limitación del tratamiento.
  • Oposición al tratamiento.
  • Portabilidad de los datos cuando resulte aplicable.

Para ejercer estos derechos, el usuario puede enviar una solicitud a:

tu@email.com

La solicitud deberá indicar el derecho que desea ejercer y proporcionar la información necesaria para poder identificar la solicitud.

Asimismo, el usuario tiene derecho a presentar una reclamación ante la Agencia Española de Protección de Datos (AEPD) si considera que el tratamiento de sus datos personales infringe la normativa aplicable.

8. Seguridad

Se han adoptado medidas técnicas y organizativas razonables para proteger los datos personales frente a pérdida, acceso no autorizado, alteración o divulgación indebida.

No obstante, ningún sistema de transmisión o almacenamiento electrónico puede garantizar una seguridad absoluta.

9. Cookies

Este sitio web no utiliza cookies destinadas a realizar perfiles de usuario, publicidad comportamental o seguimiento de la actividad del visitante.

En caso de utilizarse en el futuro tecnologías que requieran el consentimiento del usuario, se actualizará esta política y se solicitará dicho consentimiento cuando sea necesario.

10. Cambios en esta política

Esta Política de Privacidad podrá actualizarse para adaptarla a cambios legales, técnicos o relacionados con el funcionamiento del sitio web.

La versión vigente será la publicada en esta página, indicando su fecha de última actualización.
